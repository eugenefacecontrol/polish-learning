# Sessions

Здесь хранится один компактный файл на учебную сессию. Полные транскрипты не сохраняются.

## Naming

- первая сессия дня: `YYYY-MM-DD.md`;
- дополнительные сессии: `YYYY-MM-DD-02.md`, `YYYY-MM-DD-03.md`.

## Template

```md
# Session — YYYY-MM-DD

- **Duration:** N минут
- **Main quest:** ...
- **XP earned:** +N
- **Level:** N, X / 100 XP
- **Streak:** N дней

## Completed

- ...

## New vocabulary

- `polskie słowo` — значение / контекст

## Important mistakes

- 🔴 `...`
- 🟢 `...`
- Причина: ...

## Strong moments

- ...

## Skill changes

- Grammar: 40% → 42% — краткое доказательство

## Review later

- YYYY-MM-DD — что проверить в новом контексте
```
