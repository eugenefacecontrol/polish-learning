# ⚔️ Weekly challenges

## Current week

Challenge откроется после первой диагностики, чтобы его сложность соответствовала реальному уровню.

## Rules

- Один challenge проверяет практическое применение, а не зубрёжку.
- Он должен быть выполним примерно за 10–20 минут.
- Результат влияет на навыки только при наличии понятных доказательств.
