## 🚀 Как начать занятие

В новом чате достаточно написать:

> Давай польский.

Инструкция проекта уже содержит ссылку на репозиторий, поэтому дополнительно напоминать про состояние не нужно. Ассистент сначала читает [`progress/current.md`](progress/current.md), затем только нужные файлы и начинает с одного интерактивного задания. В конце занятия он обновляет состояние и создаёт компактный отчёт в `sessions/`.

## 💾 Как сохраняется результат

Для записи прогресса используется подключённый GitHub-коннектор. Инструкция сама по себе не даёт доступ к репозиторию: GitHub должен быть подключён и доступен в текущем чате.

Когда занятие закончено, напиши:

> Заканчиваем урок.

После этого ассистент:

1. подводит визуальный итог занятия;
2. создаёт `sessions/YYYY-MM-DD.md`;
3. обновляет `progress/current.md`;
4. при необходимости обновляет навыки, словарь, повторяющиеся ошибки, достижения и этот README;
5. сохраняет изменения коммитами в ветку `main`.

Это не фоновая автоматизация. Если просто закрыть чат посреди занятия, несохранённый результат может не попасть в GitHub. При нескольких занятиях одновременно ассистент должен сначала перечитать актуальные версии файлов, чтобы не перезаписать более свежий прогресс.

## 🧠 Принцип хранения

Репозиторий хранит только то, что улучшает следующие занятия. Полные транскрипты чатов сюда не копируются. История Git сохраняет изменения, а `current.md` всегда остаётся коротким.
