## 🚀 Как начать занятие

В новом чате достаточно написать:

> Давай польский. Используй состояние из <https://github.com/eugenefacecontrol/polish-learning>.

Ассистент сначала читает [`progress/current.md`](progress/current.md), затем только нужные файлы и начинает с одного интерактивного задания. В конце занятия он обновляет состояние и создаёт компактный отчёт в `sessions/`.

## 🗂 Что где хранится

- [`PROJECT_INSTRUCTIONS.md`](PROJECT_INSTRUCTIONS.md) — готовая инструкция для ChatGPT Project;
- [`progress/current.md`](progress/current.md) — единственная точка быстрого входа;
- [`progress/skills.md`](progress/skills.md) — подробное дерево навыков;
- [`progress/achievements.md`](progress/achievements.md) — полученные достижения;
- [`vocabulary/`](vocabulary/) — активные, освоенные и проблемные слова;
- [`mistakes/common.md`](mistakes/common.md) — повторяющиеся ошибки;
- [`sessions/`](sessions/) — компактная история занятий;
- [`challenges/`](challenges/) — недельные задания и боссы.

## 🧠 Принцип хранения

Репозиторий хранит только то, что улучшает следующие занятия. Полные транскрипты чатов сюда не копируются. История Git сохраняет изменения, а `current.md` всегда остаётся коротким.
